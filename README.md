# 愉阅 JoyRead

*此仓库为前端部分，去往[前端部分](https://github.com/PeerlessMonster/JoyRead_app)*

## 有啥功能 🧐

- 资讯阅读
  - 根据 ID 获取新闻内容
  - 根据 ID 获取新闻的详情信息
  - 最新资讯：按发布时间倒序，支持分页
  - 时下热门：发布时间一天 / 一周内按浏览量降序，支持分页
- 搜索资讯
  - 根据关键字混合搜索，即同时执行全文检索、语义检索再融合结果
- 资讯助手
  - 根据提问，进入聊天机器人的工作流，以混合搜索的结果为上下文生成回答
